# Fonts

xialla.com serves **Fieldwork** (and Fieldwork Hum) via Adobe Fonts / Typekit kit `shw7daa`.

Adobe Fonts webfont terms do **not** allow redistributing those binary font files inside an iOS app. Until a desktop/app license is purchased and `.otf`/`.ttf` files are dropped here:

1. Add licensed files, e.g. `Fieldwork-Regular.otf`, `Fieldwork-Semibold.otf`, `Fieldwork-Bold.otf`
2. Register them in `Supporting/Info.plist` under `UIAppFonts`
3. Ensure PostScript names match `BrandTheme.fieldwork*Name`

Until then, `BrandTheme` uses **Avenir Next** (system) at matching weights for a geometric humanist sans close to Fieldwork. Brand colors, logo, and hero imagery still apply.
