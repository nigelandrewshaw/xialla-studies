# Fonts

Bundled **Fieldwork Geo** desktop OTFs (licensed for app embedding):

| File | PostScript name |
|------|-----------------|
| `Fieldwork_Geo_Regular.otf` | `Fieldwork-Geo-Regular` |
| `Fieldwork_Geo_Demibold.otf` | `Fieldwork-Geo-Demibold` |
| `Fieldwork_Geo_Bold.otf` | `Fieldwork-Geo-Bold` |

Registered in `Supporting/Info.plist` under `UIAppFonts`. `BrandTheme.display` / `BrandTheme.body` use these PostScript names (not Avenir).

Do not replace with Adobe Fonts / Typekit webfont binaries — those licenses disallow app redistribution.
